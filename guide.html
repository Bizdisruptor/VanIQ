📖 VanIQ User Guide

v2.0 · Van Build Planner

Getting Started

VanIQ is a precision van conversion layout tool. You place modules (bed frames, cabinets, electrical boxes, etc.) onto an accurate canvas of your van interior and plan your build in multiple views.

Sign in (top right) to unlock save, share, and multi-project features.

The Canvas

Modules are drawn on the canvas as colored rectangles. Drag them to reposition. Double-click to edit. Click once to select (shows blue outline).

Module categories by color:
🟠 Utility — storage, cabinets, frames
🟢 Living — bed, galley, seating
🔵 Power — battery, inverter, electrical
🟣 Overhead — upper cabinets, ventilation
⬜ Frame — structural, floor platform

Adding Modules

Click ＋ Add Module in the right panel, or open 📦 Module Library to pick from presets. Fill in the name, dimensions (inches), category, and which side of the van.

Dimensions are interior usable space, not including frame or insulation — those are subtracted automatically from your van shell settings.

Dims Panel

The Dims tab on the right controls van shell dimensions, insulation stack, build options, and design constraints.

Insulation Preset automatically fills in wall/floor/ceiling thickness based on common build standards. Switch to Custom to override manually.

Frame rail width sets the T-slot extrusion setback used to compute usable wall width.

Constraint Checks — turn on to get real-time warnings for aisle clearance, door clearance, height limits, and module overlaps.

Anchor / Lock Position

Click any module, then open the Anchor HUD (appears when a module is selected) to lock one or more edges to a specific measurement. Locked edges cannot be moved by dragging — only by editing the value directly.

Saving Your Build

💾 Save (Ctrl+S) — saves to your account in the cloud
⬇ Export — downloads a .json backup file to your computer
⬆ Import — restores from a .json file
📥 CSV — imports a build list (items, dimensions, costs) from a spreadsheet
📋 Template — downloads a blank CSV to fill in

CSV Import

Use the CSV import to bring in your full build list from Excel, Google Sheets, or Notion. Download the template first to see the required columns:

Projects

Click the ⊕ button next to the project selector to create multiple projects (e.g., one per van model you're comparing). Requires an account.

Share

Click 🔗 to copy a share URL. Anyone with the link can view your layout (read-only). Requires sign-in and a saved project.

Resources Menu

The ⚙ Resources dropdown opens build documentation for your specific build — rack specs, water diagrams, roof layouts, and more. Use 📂 Open Local File to load any .html file from your computer.
